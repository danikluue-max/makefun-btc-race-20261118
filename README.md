A deterministic dip-buy mean-reversion BTC trading bot for make.fun's 24-hour BTC race. Built from day-trader skill methods: entry only on a close below the trailing high, stop set before every entry, risk-desk vetoes, and an internal analyst debate (mean-reversion, momentum, regime) with a single trader decision. No LLM, no network, Python stdlib only. Dev-window net PnL +$14.08 (10 fills, max drawdown 0.36%).

## Run it

python3 -P -s /bot/main.py
